# LatentGate

> **Archive:** This is the former long-form landing page. Its status and next-step sections preserve historical context; use [README.md](README.md) and [STATE.md](STATE.md) for the current handoff.

Research notes and experiment specifications for diagnosing and steering video-generation models for robot manipulation.

## Project question

Can we inspect the internal spatiotemporal states of a general-purpose video generator, locate representations for geometry, identity, motion, camera, and contact, and steer those states with small modular policies? If so, do the resulting videos improve robot learning enough to substitute for some real demonstrations?

The proposed scientific chain is:

```text
observe → localize → intervene → ablate → compose → measure downstream value
```

The target is useful, diverse, robot-relevant synthetic data—not video quality alone.

## Core hypotheses

1. **Observability:** intermediate latents and transformer states reveal robotics-relevant variables before final decoding.
2. **Correctability:** interventions on selected states causally change the corresponding generation failures.
3. **Synthetic substitution:** improvements in physical consistency and task fidelity reduce the amount of real robot data needed at matched downstream performance.

All three remain open. A variable being readable from a hidden state does not show that it can be controlled, and a prettier video does not establish downstream utility.

## Research and evaluation rules

- Treat specialist models and simulator state as teachers; use lightweight probes to test what the generator represents; evaluate with an independent verifier where possible.
- Separate observability, early failure prediction, causal correctability, action-specific routing, and downstream utility.
- Record model revision, prompt, seed, scheduler, frame count, resolution, policy strength, active layers/timesteps, teacher/evaluator versions, runtime, VRAM, and output hashes.
- Measure real-data substitution at equal robot-policy performance. Do not assume more synthetic data is better.
