# Object-state video diffusion feedback: source audit and Gate 0 status

**Updated:** 2026-10-02  
**Scope:** fixed-camera, single-object image-plane path control, followed by a possible object-state-feedback policy.  
**Execution status:** scorer contract validated on deterministic CPU fixtures and paired Kubric/Blender CPU renders; two blinded reliability-labeling packages are ready, but annotation-reliability measurement remains open. No model inference, paid compute, account prompt, or pilot-runner modification was performed.

## Decision

Gate 0 was the earliest incomplete evidence gate. The scorer contract now passes deterministic PIL checks and a paired Kubric/Blender render fixture: 34 CPU-rendered frames with segmentation masks and camera-projected point truth. Both directions retain 16 valid adjacent pairs, have the expected signed endpoint displacement, and score below 0.03 frame-diagonal center ADE. The remaining Gate 0 item is a small, randomly selected frame subset labeled independently by two annotators to estimate annotation disagreement. Keep the gate open until that reliability check is recorded.

The best next method comparison remains a direction-neutral, shared-start, mirrored-path test of no control, foreground/background path control, and full DiTraj under matched seeds and noise. The current repository M0 clip has prompt direction leakage and is only a generation reference. The active pilot runner remains unchanged.

## Gate 0 artifact and contract

- [Scorer source](path_annotation_scoring.py) reads blinded, structured per-frame boxes and evaluates center ADE, endpoint FDE, box IoU, signed x displacement, target-aligned endpoint progress, object visibility, identity scoreability, and duplicate counts.
- [Validation script](validate_gate0_scorer.py) makes 17-frame exact left/right synthetic paths and checks interpolation, sign, normalized error, missing/identity-ambiguous penalties, missing-frame adjacency denominators, duplicate detection, external unblinding key separation, and CSV round-trip.
- [Kubric fixture builder](render_gate0_kubric_fixture.py) creates rightward and leftward 17-frame scenes, captures RGB/segmentation outputs, projects known object centers with Blender's render-camera transform, derives boxes from the object mask, and runs those rows through the same scorer.
- [Rendered Kubric fixture](kubric_gate0_fixture_v1/fixture_report.json) records the source revision, runtime versions, masks, point truth, and per-arm scores. [Two blinded annotation copies](kubric_gate0_annotation_reliability/package_manifest.json) are prepared with private keys outside their ZIPs. [Validation record](gate0_scorer_validation_v1.json) reports `kubric_rendered_truth_scored_annotation_reliability_pending`; its checks cover rendered scoring and package isolation, while human agreement itself remains unmeasured.

Scoring choices to keep fixed for the next gate:

1. Every expected frame needs an explicit annotation row. Missing or identity-ambiguous frames receive 1.0 frame-diagonal center error and zero box IoU; they remain in the ADE denominator.
2. Report valid-only ADE only as a diagnostic beside missing-penalized ADE and scoreable identity coverage. A missing endpoint receives the maximum FDE penalty.
3. Compute x monotonicity only over consecutive frame indices whose two observations are scoreable. Report that pair denominator; never bridge a missing interval.
4. Report duplicate count, visibility, identity failures, and box/shape guards separately from trajectory accuracy. Endpoint displacement is undefined if either endpoint is unscoreable, so coverage and FDE must accompany it.
5. The package uses opaque random clip IDs, re-encodes PNGs to remove incidental metadata, and keeps the arm mapping in a separate key file. It is a useful blind-labeling scaffold, not a substitute for a second annotator or a check that the annotations are reliable.

The existing color-threshold evaluator is not suitable as the primary scorer: it detects a red proxy, and its compact-valid-center monotonicity can bridge missing frames. The pilot template also stored identity/quality judgments as free text. These issues were handled in standalone research utilities; the runner was not changed.

The source audit establishes collisions, not that a remaining mechanism is novel. In combination, DiTraj, TrajLoc, CausalMotion, Self-Refining, and MotionAgent rule out broad claims around trajectory control, target heatmaps, state-conditioned path guidance, sampling-time refinement, or video-feedback correction.

## Candidate hypothesis and falsifiers

The remaining testable hypothesis is deliberately narrow: **for a fixed target path, measuring the object's position from a selected predicted-clean estimate and feeding its signed target error plus calibrated confidence into the next denoising control update reduces held-out path error beyond open-loop DiTraj and compute-matched generic refinement.** This is not yet a novelty claim.

The comparison should include no control, fixed DiTraj, a compute-matched fixed schedule/gain, state-feedback, zeroed-state and shuffled-state ablations, and a generic self-refinement control if a runnable local implementation fits the same inference budget. Keep prompt, start location, latent noise, sampler, decode path, and denoiser-call budget matched. Use neutral prompt text and mirrored paths that start at the same center and end equal distances in opposite directions. Have annotators blinded to path and method labels.

Reject the feedback hypothesis if any of these hold:

- A fixed schedule or generic self-refinement control matches the feedback gain.
- Zeroing or shuffling the observed state preserves the gain.
- The estimate cannot predict manually labeled centers on held-out seeds better than a constant/prompt-only predictor, or its confidence is uncalibrated.
- Direction response is wrong, prompt or initial state leaks direction, or matched noise/control execution cannot be verified.
- A path-score gain comes from hiding, shrinking, duplicating, recoloring the object, or moving the background/camera.

The current pooled transformer summaries `[1,5,1536]` cannot localize the object. Any later observer experiment needs spatial features or decoded predicted-clean frames at selected denoising steps, labeled independently of the control policy. Do not infer local state observability from those pooled summaries.
