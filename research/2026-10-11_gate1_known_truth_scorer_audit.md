# Gate 1 known-truth scorer audit

**Updated:** 2026-10-11 15:13 UTC (initial audit 14:45 UTC)  
**Component:** Gate 1 human reference labels for fixed-camera 2D path measurement.

## Decision

Keep Gate 1 at the human-reference reliability step. Add a separate known-truth diagnostic so two raters cannot appear reliable solely because they share the same coordinate or box-placement bias. After two complete v5 CSVs pass the registered blinded inter-rater screen, score each rater independently against both (a) the Kubric mask-derived box and (b) the continuous projected object center. Preserve the existing inter-rater screen and do not add a new pass threshold here.

This follows the measurement plan already recorded in the [native-scale path measurement memo](2026-10-02_fixed_scale_path_measurement_memo.md), which calls for comparing each Kubric rater with exact projected truth, and the [Kubric/MOVi fixture specification](kubric_gate0_fixture_v1/README.md), whose local JSON records RGB, binary masks, projected centers, and mask-derived boxes. The broader annotation literature, dataset caveats, and metric choices remain in the [Gate 1 method survey](2026-10-03_gate1_annotation_method_followup.md); this is a measurement addendum, not a new literature claim.

## Implementation and CPU validation

- [`score_gate1_labels_against_kubric_truth.py`](score_gate1_labels_against_kubric_truth.py) validates both complete rater CSVs and identical blind clip/frame keys, recomputes the registered pooled/per-clip agreement screen, and opens the private key only after that screen passes. The agreement thresholds are imported from the primary scorer's shared defaults to prevent silent drift. It reports category accuracy and visible-box coverage separately from center errors, signed x/y bias, box IoU, and edge errors, both per mirrored clip and pooled. Source-to-grid deltas use the same mapping helper as the inter-rater scorer. It also reports the mask-box-midpoint to projected-center representation gap.
- Completeness alone did not establish that the pair met the pre-unblind reliability screen. A deliberately below-threshold two-clip pair is now rejected before key access; the oracle supplies a nonexistent key path to make an accidental early read observable.
- [`validate_gate1_truth_scorer_oracle.py`](validate_gate1_truth_scorer_oracle.py) creates exact-oracle CSVs only in a temporary directory, invokes the actual scorer, and deletes the CSVs on exit. Its output is [`gate1_truth_scorer_oracle_selfcheck_v1.json`](gate1_truth_scorer_oracle_selfcheck_v1.json).
- Exact fixture-derived labels score 34/34 frames with 0.0 px center error, categorical accuracy 1.0, and mean box IoU 1.0. For the common-mode check, both identical synthetic CSVs receive the same +2.0 source-pixel x shift: each rater still matches the other exactly, while the truth audit reports +2.0 px signed bias, 0.65 horizontal control-grid cells, and mean box IoU 0.8182. This confirms the diagnostic can reveal a shared bias that pairwise agreement alone would miss; it is not evidence that either human rater has such a bias.
- The geometry guard excludes frames when either a rater or the known fixture truth marks the visible target non-unique or identity-uncertain, while retaining those frames in categorical accuracy and visible-box coverage denominators. Separate synthetic cases for an annotator identity-uncertain label, truth identity uncertainty, and a duplicate-target truth each retain visible-box coverage but reduce uniquely identified geometry coverage from 34/34 to 33/34. This keeps path localization separate from visibility and identity.
- The fixture's continuous projected centers and mask-box midpoints differ by a mean 0.00000163 source px in this render, consistent with floating-point serialization. Keep both references in the report so later fixture changes cannot silently collapse the distinction.
- Updated oracle validation, including six scorer subprocesses (five accepted synthetic cases plus one blocked below-threshold pair), took 0.297363 s on Darwin arm64 / Python 3.12.3. CPU only; GPU false, peak VRAM null, no model inference, cloud runtime, or external data download. The local fixture pins Kubric commit `61f2422c84bab75006df33c6989e0b483db3ccfe`; the fixture README does not state upstream license terms, which were not re-audited here. No fixture or upstream source was redistributed.
