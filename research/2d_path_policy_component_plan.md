## Components and exit gates

| Box | Question | Required evidence to pass | Stop or redesign when |
|---|---|---|---|
| 0. Task and prompt isolation | Can the target path, camera, prompt, and object be specified without giving direction away in text? | Neutral prompt, fixed camera/background, normalized boxes, target path hash, fixed model/sampler/seed. Pair mirrored paths that share the same first-frame box and initial noise, then diverge toward equal-distance endpoints. | Prompt names the same direction as the target, start box differs across the direction pair, background moves with the object, or requested boxes do not map to the model's latent-time grid. |
| 1. Object measurement | Can one instance be tracked and scored independently of the path input? | Tracker/mask output on all 17 RGB frames, blinded manual corrections, object-identity/visibility labels, center and box per frame. Record tracker confidence and missing frames. | Tracker follows the background, switches/duplicates objects, or scoring relies only on the same color threshold used to find the object. |
| 2. Scene and geometry guardrails | Did the path gain come by changing the scene or corrupting the object? | Background feature/flow stability; visibility and duplicate count; box width/height and mask-area stability; blinded clip-quality review. | Object disappears, duplicates, changes identity/size materially, or camera/background motion explains the apparent path. |
| 3. Matched open-loop baseline | Does DiTraj improve path response over the same unmodified Wan sampler? | Base / prompt-separation / full DiTraj, matched noise and settings, both path directions; log control masks, peak VRAM, wall time, artifacts and code hashes. | Any arm differs in prompt, noise, sampler, path decoding, or active-mask assumptions; stop before seed expansion if runtime smoke fails. |
| 4. State observability | Can an internal or predicted-clean state estimate object position, path residual, and confidence? | Spatially preserving features (current M0 summaries are spatially pooled and cannot localize the object); held-out seed/path probe beats a constant or prompt-only predictor; calibration and confidence coverage reported. | The observer is not better than a trivial baseline, leaks target path labels, or its confidence is uncalibrated. |
| 5. Actuator identification, then latent state feedback | Does the actual changed control channel move the rendered object, and later does generated-state error improve that action? | First pass the mirrored open-loop Base / FG-BG / full DiTraj pilot. Then run two separate sensitivity checks: (a) full-run target-box shifts, which include early RoPE; (b) a shared-prefix post-step-4 static 0, ±1, ±2-cell update to future cross-attention masks, with original RoPE frozen. Verify identical prefix state, mask changes, correct sign, and independent output labels. Use one seed only as plumbing/directional screening; use at least eight paired seed blocks before calling the action sign calibrated. Only then test live feedback with no-op, fixed-action, shuffled-state, and sign-reversed controls. | Full DiTraj is not path-responsive; prefix or scheduler state diverges; mask updates change no tokens; ±1 is null and ±2 is not (classify ±1 as below the measurable dose); neither dose produces repeatable signed output, or guardrails fail; feedback gain survives state shuffling/zeroing or is matched by a fixed schedule. |
| 6. Held-out confirmation | Is the delta repeatable across seeds and unseen path shapes? | Paired seed results, both directions plus a piecewise/reversal path, independent scoring, confidence intervals, all failed/unscoreable samples retained. | Gain fails on reversed/held-out paths, collateral quality worsens, or uncertainty spans no improvement. |

## Measurement contract (first audit reconciled; experimental validation pending)

Primary path metric: annotate tight visible-object box midpoints at native 832×480 resolution and score continuous pixel centers against the original requested path; also report frame-diagonal-normalized ADE, endpoint error, signed response, and cell units (`pixels / 16`) for interpretation. Do not round observed centers to the 52×30 control grid: nearest-cell scoring erased 5/16 and 6/16 steps in the existing Kubric mirrors and added 9.23 px RMS error. Keep missing, duplicate, ambiguous-identity, and absent frames in the denominator with the predeclared penalty and report coverage separately. The local paired-path notebook uses a direction-neutral prompt and mirrored paths with the same first-frame box and shared initial noise. This is the right causal comparison when staged; the separately saved M0 clip's left-to-right prompt remains a baseline feasibility sample and cannot establish that box guidance caused its direction.

Use blinded, framewise manual box/center/visibility labels as the small-pilot adjudicator. A first-frame-initialized tracker or segmentation model can propose labels, but the red threshold and any policy-side tracker are secondary only. In particular, a point tracker on a rolling sphere follows a surface patch, not necessarily the projected object center. DiTraj's published OWL-ViT-Large scores (coverage, mIoU, center distance, AP50) can be retained for method comparability, not identity ground truth. The red-mask overlays show specular-highlight holes. Track static background features separately to detect camera/table motion; report apparent size and mask-shape variation as guardrails, not metric 3D geometry. The generated-output background method and [calibration preregistration](2026-10-17_ditraj_background_calibration_prereg_v1.md) are recorded in the October 17 memos; no background acceptance threshold is calibrated yet. [DiTraj evaluation protocol](https://arxiv.org/html/2509.21839v2)

Initial signal threshold for a small exploratory set: at least 20% lower paired normalized path error than the unsteered control, at least 90% object visibility, and no material worsening of apparent size, background stability, identity, or blinded quality. This is a pilot gate, not final statistical evidence. If it passes, repeat across at least five matched seeds and report paired intervals before claiming an improvement.
