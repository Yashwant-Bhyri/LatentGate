# Global literature and collision review: video path control and step-4 residual feedback

**Review date:** 2026-10-02  
**Target:** fixed-camera, one-object, 2D image-plane path adherence, with a possible same-sample feedback update during Wan/DiTraj denoising.  
**Evidence boundary:** primary papers and official project/code pages were checked for the methods below. This is a decision-directed landscape map, not a claim of exhaustive bibliographic coverage. No code was changed and no model inference was run for this review.

## Executive finding

Trajectory-conditioned video generation is a mature research area across training-free noise/attention control, test-time latent guidance, learned trajectory adapters, dense point-track conditioning, and simulator/world-model control. A claim such as “first latent trajectory guidance,” “first predicted-clean correction,” “first self-correcting video diffusion,” or “first online video control” would collide with established work.

The current intervention is narrower: **after one step-4 predicted-clean estimate, measure the object’s image-plane center, compute its signed error against five commanded path locations, and update the remaining DiTraj spatial cross-attention masks for that same sample.** It is one measurement-driven update, not repeated receding feedback, not a gradient update to the latent, and not a change to model weights. It is a hypothesis, not a demonstrated improvement or a novelty claim.

The fairest first causal comparison is the same Wan 1.3B/DiTraj run with shared prompt, path, scheduler, and initial noise. The minimum informative matrix has six arms: open-loop DiTraj, decode-matched no-op, calibration-frozen static correction, live signed residual, temporally shuffled residual, and sign-reversed residual. A successful mechanism smoke is a prerequisite; it is not an efficacy result.

## Evidence grades

- **A — inspected primary evidence:** full or relevant sections of the paper plus official repository/project details were checked. Local implementation/source behavior was inspected when stated.
- **B — primary-source summary:** paper abstract or official project/repository README was inspected, but code or detailed appendix behavior was not independently verified in this pass.
- **C — contextual lead:** method is included to mark a likely collision or adjacent direction; exact artifacts or complete method details remain to be checked before implementation.

Paper-reported performance is identified as a paper claim; repository status describes what the official public page exposed at review time. Checkpoint terms can differ from source-code terms.

### What is mature, and what remains open

1. **Mature:** accepting explicit 2D tracks, boxes, masks, or motion fields and steering generation with open-loop inputs. Methods span noise warping, temporal attention, feature propagation, spatial token masks, and learned adapters.
2. **Mature:** test-time use of intermediate/predicted-clean states. Frame Guidance applies task losses to clean predictions; PSIVG uses simulator-derived geometry/trajectories; self-refinement repeatedly predicts and perturbs. Generic “we inspect a clean estimate and guide diffusion” is occupied.
3. **Mature:** DiT temporal features can encode useful point correspondences. DiffTrack and follow-on tracking work show potential for internal observers, but do not establish a general, well-calibrated control-state estimator for our task.
4. **Not yet established by the reviewed sources:** whether a cheap, externally validated object-state measurement at an intermediate denoising step can improve a *single* Wan/DiTraj sample over a strong fixed open-loop path schedule, and whether the signed, time-aligned residual is the cause of any improvement.
5. **Not established:** that any improvement survives identity, visibility, shape/extent, scene-quality, and background-motion checks, or transfers beyond a red-ball proxy and 2D fixed-camera path task.

## Benchmarks and measurement caveats

| Benchmark/source | Useful evidence | Limitation for this experiment |
|---|---|---|
| [DiTraj paper](https://arxiv.org/abs/2509.21839) | Detector-based box coverage, center/IoU/trajectory metrics. | Detector and red-mask scores cannot establish identity or recover missing-object failures by themselves. |
| [MoveBench](https://github.com/ali-vilab/Wan-Move) | Wan-family motion-control examples and trajectory/first-frame annotations; the repo says first-frame masks were added for evaluation. | 14B I2V and annotation/evaluation release details differ from our matched 1.3B T2V sample. |
| [MagicBench](https://huggingface.co/datasets/quanhaol/MagicBench) and [MagicData](https://huggingface.co/datasets/quanhaol/MagicData) | Multi-object/control-type stratification and trajectory/video quality design. | Official README announces MagicBench release, but its HF card appeared empty and the README still marks benchmark evaluation code TODO; conditions and backbones differ. |
| [FlexBench](https://huggingface.co/datasets/bestzzhang/FlexBench) | Dense, spatially sparse, temporally sparse, and unaligned trajectory controls. | Small external stress set, not a same-seed counterfactual for this controller. |
| [VBench](https://arxiv.org/abs/2311.17982), [VBench-2.0](https://arxiv.org/abs/2411.13503) | Subject/background consistency, temporal and perceptual quality guards. | General video quality does not measure adherence to a specified object path. |
| [T2V-CompBench](https://arxiv.org/abs/2407.14505) | Object/action binding, interaction, and spatial-relation probes. | Not an externally commanded continuous path benchmark. |
| [TAP-Vid / TAPNet](https://github.com/google-deepmind/tapnet) | Point track and visibility protocols; useful independent motion cross-check. | A tracked sphere surface point is not its projected center; tracker output is not ground truth for the target path. |
| [Kubric](https://github.com/google-research/kubric) | Rendered clips with known masks, depth, camera, and object trajectories for scorer validation. | Synthetic truth validates tools and planned controls, not labels on generated Wan clips. |

For generated clips, use blinded manual labels as the primary small-study evaluator. Annotators should not know treatment arm or target path while marking visibility, identity/count, center, and box/mask. Report missing coverage and missing-penalized center ADE/FDE, commanded-direction endpoint displacement, and guardrails separately: object identity/duplicates, apparent area/box extent, and static-background movement. A detector, red threshold, SAM, or point tracker may propose/check labels, but must not be the sole evaluator—especially if the same signal controls the model.

## Current adapter evidence boundary

Local evidence inspected on 2026-10-02:

- `research/ditraj_feedback_adapter.py` implements an opt-in one-read feedback hook. It checks the UniPC conversion configuration, captures the converted clean estimate at zero-based step 4, decodes via the Wan VAE, observes red pixels over all frames, uses frame indices `[0, 4, 8, 12, 16]`, calibrates static start offset, bounds the action to one token, locks the initial box, and updates later cross-attention masks only when the rasterized mask changes.
- `research/ditraj_unipc_capture_smoke_v1.json` records a successful **CPU scheduler capture** against Diffusers 0.33.1 with zero maximum difference from its expected conversion.
- `research/m0_step4_feedback_mechanism_diagnostic_v1.json` is an offline counterfactual over one previously generated, text-only M0 clip; it reports 71 rasterized token changes but explicitly does not rerun denoising. This is not a DiTraj treatment result.
- `research/run_ditraj_feedback_pilot.py` currently includes only open-loop DiTraj, decode-matched no-op, and live feedback; the default is eight denoising steps. The integrated `feedback_smoke_report.json` was not present in the workspace at review time. At eight steps, indices 5–7 remain after the step-4 observation—too few to judge efficacy. Under the 30-step schedule with `mask_step=18`, the update can influence steps 5–17 (13 transformer calls).
- The update changes text-to-spatial cross-attention assignment, not pixel position directly. A nonzero mask change proves actuation plumbing only. The red observer’s agreement score is an uncalibrated heuristic; starting-position anchoring can hide an absolute start error, so raw start localization must be reported separately.

## Smallest matched efficacy matrix after the integrated smoke

Use the full 30-step schedule. Keep the same model revision, prompt embeddings, negative prompt, scheduler, guidance, target boxes, initial latent tensor, and VAE preview checkpoint. Use a direction-neutral prompt and pair mirrored left/right target paths. Within each seed/path block, reuse the identical noise across arms. Compute token shifts from rasterized masks, because a continuous sub-token correction may produce no actual intervention.

| Arm | Intervention | Test |
|---|---|---|
| **A** | Full open-loop DiTraj; no extra step-4 decode | Same-backbone reference. |
| **B** | Step-4 decode/observer; zero residual | Compute-matched no-op. Require exact frame-array equality with A; otherwise stop and investigate. |
| **C** | A fixed path-correction schedule calibrated on disjoint clips; still run the same step-4 observer/decode but ignore this sample’s state | Does generic, sample-independent path compensation explain the effect? Freeze schedule before evaluation. Match aggregate rasterized shift budget without tuning on held-out clips. |
| **D** | Correctly signed, time-aligned residual from this clip’s step-4 clean estimate | Primary hypothesis. |
| **E** | Permute D’s residual vectors over unlocked path keyframes, preserving the residual set/action budget | Does framewise temporal correspondence matter? Lock the start as in D. |
| **F** | Sign-reverse D’s residual vectors | Does action direction matter? Apply identical cap/gain/confidence rules. |

All B–F must perform the same decode and observer work. Keep gain, cap, observer threshold, permutation rule, and static schedule fixed before the evaluation seed set. If the observer is tuned, reserve fresh clips for efficacy. Validate its step-4 centers and visibility/identity acceptance against independent blinded labels first; same-color threshold agreement on the same generated clip is not independent validation.

**Falsification rules:**

- Reject the mechanism smoke if B differs from A, the capture is at the wrong scheduler step/configuration, the observed state cannot be independently scored, the mask/token map is wrong, or D produces no rasterized change. A passing smoke means only that capture/decode/observer/action/rebuild works and fits the resource budget.
- Reject the sample-specific-feedback hypothesis if D does not beat both B and C on held-out seed blocks, or if shuffled E and sign-reversed F perform comparably. If C matches D, prefer the simpler fixed compensation and do not attribute the gain to live feedback.
- Reject a path improvement if it results from disappearing/shrinking objects, identity changes/duplicates, or camera/background drift. Any red-proxy gain must also appear under blinded human labels.
- Keep the seed pair as the inference unit; frames from one clip are not independent samples. A five-block run is a directional screen. Use at least ten paired seed blocks before making an improvement claim, with uncertainty intervals and all failures retained.

## Ranked next research questions

1. **Can the current step-4 measurement-driven residual outperform a calibration-frozen static path correction?** This is the highest-value next question because it tests whether sample-specific observation matters beyond known baseline under-travel. Falsified if C equals or beats D on held-out seed blocks, or D’s advantage does not survive human labels and guardrails.
2. **Is the bottleneck state estimation or actuation?** If observer labels are reliable but D fails to beat B/C, test whether changing cross-attention masks can move the generated object at all. A mask update without a signed output displacement is a failed actuation assumption. If red detection fails, do not interpret controller efficacy; test a spatial DiT feature/QK reader (e.g. DiffTrack-style) against the same blinded annotations first.
3. **Does repeated later feedback add value beyond a single read?** Only after the one-read arm passes. Compare additional step-14 feedback against a decode-matched no-op and static schedule; more feedback costs VAE work and may induce saturation or content simplification, a failure mode reported by self-refinement work.
4. **Can an observer/action law become a native latent policy?** Only after causal measurement and actuation survive. Capture spatially retained latent/attention states, train a small state reader on independent generated/rendered clips, and test held-out scenes and paths. Do not infer that an opt-in mask patch is a native policy or weight improvement.

## Source and artifact notes

The method links in the main table point to primary papers and official projects/code where available. Repository pages were reviewed as release evidence, not as a blanket grant for downstream use. At minimum, preserve these checks before any method reuse: (1) exact code commit, (2) code license and any non-commercial/attribution terms, (3) model/checkpoint license separately, (4) dataset/benchmark terms, (5) actual inference model and memory requirements.
