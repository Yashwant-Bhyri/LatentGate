Blinded per-frame annotation instructions
For each frame, record whether the target object is visible, the number of visible instances, whether identity matches the same object as frame 0, and a tight pixel-edge bounding box. Coordinates are continuous image-edge coordinates in [0,width] x [0,height]; x2/y2 are the right/bottom edges. The scored object center is the midpoint of this box. If invisible, use instance_count=0 and leave all four box coordinates blank; if visible but identity is ambiguous, set identity_consistent=false. Annotate without consulting any target path or method labels. Record occlusion, blur, or shape concerns in notes.
